# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.2.x   | yes       |
| < 0.2   | no        |

## Reporting a vulnerability

Please do **not** open a public GitHub issue for security vulnerabilities.

Open a private security advisory instead:

1. Go to <https://github.com/Tzinny-dev/modeltest/security/advisories/new>
   (or use the *Report a vulnerability* button on the repository Security tab).
2. Describe the vulnerability, the affected versions, and how to reproduce it.
3. You will get a response within a few days; we will coordinate a fix and
   credit you in the advisory unless you prefer to stay anonymous.

Please include a minimal reproduction (suite YAML, model/data setup or code
snippet) whenever possible — it speeds up triage a lot.
